# APEX / MOTION

An original, responsive automotive scroll-animation concept, built with HTML, CSS and vanilla JavaScript. Features a realistic top-view BMW car image, scroll-driven road animation, reading progress indicator, animated counters and reduced-motion support.

## Run
Open `index.html` in a browser, or serve the folder using any static server.

## Deploy
Deploy as a static site using GitHub Pages or Vercel. No build command required.

Independent concept; not affiliated with BMW or any other vehicle manufacturer.

Car image is loaded from [Gowthaman2008/itzfizz-animation](https://github.com/Gowthaman2008/itzfizz-animation); credit belongs to the original project and its asset owner. This is an independent fan concept, not an official BMW website.
